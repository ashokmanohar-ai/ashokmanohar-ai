Project case study

Smart Test Designer

RAG-powered test design that grounds scenario generation in enterprise knowledge, traceability and evaluation.

View architectureBack to projects

Challenge

Generic LLM test generation can miss domain context, duplicate existing coverage and provide weak traceability back to requirements and knowledge sources.

Solution

A test design platform combining retrieval-augmented generation, contextual knowledge, scenario generation, regression workflows, evaluation and reusable exports.

Architecture

Requirement + project context → retrieval → test generation → quality evaluation → traceability → scenarios, reports and exports.

Technology

Python, RAG, ChromaDB/vector retrieval, Azure OpenAI-compatible model integration, REST APIs and multi-tenant application patterns.

Quality Strategy

Retrieval quality checks, LLM-as-a-Judge, traceability, duplicate review, coverage review and configurable positive/negative/edge scenario generation.

Security

Tenant/project separation, controlled knowledge ingestion, scoped API access and credentials kept outside source control.

Results / Value

Shows how AI-assisted test design can become an engineering workflow with grounding, evaluation and traceability rather than a prompt-only utility.
