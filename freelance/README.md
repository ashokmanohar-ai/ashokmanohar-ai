# AI Quality Consulting — Ashok Kumar Manohar

A focused public consulting landing page connecting LLM/RAG evaluation and UI/API automation services to existing public engineering evidence.

## Run locally

Use any static HTTP server in this directory, for example `python -m http.server 8080`, then open localhost:8080.

No build step, model provider, API key or server-side runtime is required. The release gate interaction is a deterministic local illustration with synthetic values. It does not evaluate real outputs.

## Content provenance

Employment outcomes and background are based on the supplied CV. Linked repositories are reference implementations and are explicitly distinguished from enterprise delivery results. The page publishes no phone number, home address, private repository contents or client data.

## Search and accessibility

The page includes a canonical URL, description, social metadata, Person structured data, sitemap, robots file, semantic headings, labelled interactive controls, a skip link, visible keyboard focus and reduced-motion support. Search indexing and ranking are not guaranteed.

## Hosting

Intended Vercel project: `ashok-ai-quality-consulting`. Production URL: https://ashok-ai-quality-consulting.vercel.app/

The public source is maintained in the `freelance/` directory of https://github.com/ashokmanohar-ai/ashokmanohar-ai. Deploy this directory as static files. Changes to GitHub do not deploy automatically unless a Git integration is configured.
